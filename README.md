## 🇬🇧 English

A fast, searchable reference for Python learners and working developers. Browse concise explanations, tables, and copy-ready examples in one interactive page—no framework or build step required.

### ✨ What’s inside

- **30 topic areas and 200+ recipes**, from core syntax and data structures to advanced Python.
- **Bilingual English and Russian localization** with instant in-page switcher, persistent language memory, and auto-detection.
- **Modern Python coverage**, including type hints, pattern matching, async programming, and Python 3.12+ features.
- **Real-world ecosystem topics**: web frameworks, databases, data science, testing, and DevOps tools.
- **Interactive search and category filters** to get to the right snippet quickly.
- **Copyable code examples**, responsive navigation, reading progress, and keyboard shortcuts (`/` or `Ctrl+K` / `Cmd+K` to search; `Esc` to clear).
- **A lightweight static site** built with vanilla HTML, CSS, and JavaScript — 100% static and GitHub Pages ready.

### 🚀 Try it locally

No dependencies or build tools needed. Clone the repository and open `index.html` in your browser:

```bash
git clone https://github.com/python-cheat-sheet/python-cheat-sheet.github.io.git
cd python-cheat-sheet.github.io
```

Or visit the [live cheat sheet](https://python-cheat-sheet.github.io/).

## 🇷🇺 Русский

Быстрый интерактивный справочник по Python для тех, кто учится и пишет код каждый день. Ищите короткие объяснения, таблицы и готовые к копированию примеры — всё на одной странице, без фреймворков и сборки.

### ✨ Что внутри

- **30 тематических разделов и 200+ рецептов**: от основ синтаксиса и структур данных до продвинутого Python.
- **Двуязычная локализация (Русский / English)**: мгновенный переключатель в интерфейсе, запоминание выбора и автоопределение языка.
- **Современный Python**: аннотации типов, сопоставление с образцом, асинхронность и возможности Python 3.12+.
- **Практические темы экосистемы**: веб-фреймворки, базы данных, Data Science, тестирование и DevOps-инструменты.
- **Интерактивный поиск и фильтры по категориям**, чтобы быстро находить нужное.
- **Примеры кода с копированием**, адаптивная навигация, индикатор прогресса и горячие клавиши (`/` или `Ctrl+K` / `Cmd+K` — поиск; `Esc` — очистить).
- **Лёгкий статический сайт** на чистом HTML, CSS и JavaScript — без бэкенда, готов к публикации на GitHub Pages.

### 🚀 Запуск локально

Зависимости и сборка не нужны. Склонируйте репозиторий и откройте `index.html` в браузере:

```bash

cd python-cheat-sheet.github.io
```

Или откройте [онлайн-версию справочника](https://python-cheat-sheet.github.io/).
